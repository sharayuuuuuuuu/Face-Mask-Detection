# Face Mask Detection System

## Description
This project is a real-time Face Mask Detection system built using Python, OpenCV, and Deep Learning.

It detects whether a person is wearing a mask using a webcam and a trained deep learning model.

## Technologies Used
- Python
- OpenCV
- TensorFlow
- Keras
- NumPy
- Deep Learning

## Features
- Real-time face detection
- Detects mask and no-mask faces
- Webcam-based detection
- Deep learning model training

## Dataset
Dataset sourced from Kaggle for educational and portfolio purposes.

## Files
- detect_mask.py → Runs real-time detection
- train_mask_detector.py → Trains the model
- mask_detector.keras → Saved trained model

## How to Run

1. Install required libraries

```bash
pip install -r requirements.txt
```

2. Run detection system

```bash
python detect_mask.py
```
